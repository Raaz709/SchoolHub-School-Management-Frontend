# SchoolHub Frontend (React + TypeScript + Vite)

SchoolHub is a comprehensive School ERP web application consuming the ASP.NET Core API backend.

## Design System & UI
- **Modern Teal & Mint Theme**: Built with dark teal sidebar (`#32524f`), mint accents (`#3b6e68`, `#52ab98`), and clean bento grid cards.
- **Visual Reference Alignment**: Redesigned from scratch to match the reference design layout featuring the Login Portal with vector illustration placeholders, Dashboard with welcome banner, attendance circular chart, to-do list, grade report bar chart, today's classes list, school news update, and interactive sidebar navigation.

## Implemented Features

### 1. Login Screen
- "School Management System" branding.
- Vector illustration card placeholders.
- WELCOME login card with Student ID, Password, Forgot? link, Login button, and Contact IT Support.

### 2. Dashboard Screen
- Dark teal sidebar navigation (Dashbord, Classroom, News, Attendance, E-Library, Payment, Reports).
- Top search bar, notification bell, and student profile (Idris Yusuf).
- Welcome banner with greeting and Albert Einstein inspirational quote.
- Bento cards:
  - Attendance circular progress meter (92%).
  - Interactive To Do List with task completion checkboxes and "+ Add a new task".
  - Grade Report semester comparison bar chart.
  - Today's Classes schedule list (UNIX & C PROGRAMMING, Material Design, Control System).
  - School News & Update announcements from Principal and Vice-Principal.

### 3. Classroom & Attendance Views
- Enrolled courses grid (Ornithology 201, Botany 201, Food Chemistry 101).
- Detailed attendance analytics and progress breakdown.

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS / Lucide Icons
- ASP.NET Core API Backend (C# / Entity Framework)
